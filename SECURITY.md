# Security Policy

## Reporting a vulnerability

Please do not disclose a suspected vulnerability in a public issue.

Use GitHub's private vulnerability reporting from the repository's **Security** tab. Include the affected file or workflow, reproduction details, potential impact, and any suggested mitigation. The maintainer will acknowledge a complete report as soon as practical and coordinate disclosure after a fix is available.

This repository contains agent instructions and local utility scripts. Reports about prompt-injection risks, unsafe file handling, credential exposure, dependency confusion, or instructions that could cause unintended destructive actions are in scope.

## Supported versions

Security fixes are applied to the latest commit on `main`. Older snapshots and third-party forks are not maintained by this repository.
