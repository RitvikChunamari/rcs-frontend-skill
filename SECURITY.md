# Security Policy

## Reporting a vulnerability

Do not disclose suspected vulnerabilities in public issues. Use GitHub's private vulnerability reporting from this repository's **Security** tab.

Include the affected file or workflow, reproduction details, potential impact, and any suggested mitigation. Prompt-injection risks, unsafe file handling, credential exposure, dependency confusion, and instructions that could cause unintended destructive actions are in scope.

Security fixes apply to the latest commit on `main`. Older snapshots and third-party forks are not maintained by this repository.
