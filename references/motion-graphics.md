# Direct a motion graphic

Use this route for a brand ident, kinetic headline, product film, data narrative or seamless loop. For hover, navigation and ordinary component transitions use [motion](motion.md). A successful graphic should still communicate its idea as a single frame.

1. Set the delivery: message, audience, placement, aspect ratio, duration, playback trigger and final takeaway. If embedded in a page, never delay navigation to play the ident.
2. Design three stills first: opening silhouette, decisive transformation, resolved lockup. Check each at actual mobile size. Pick one visual metaphor specific to the subject: for a print studio, registration marks can converge into its monogram. Avoid a collection of unrelated reveals.
3. Write a beat sheet in seconds or frames. Give each beat a focal object, verb, start/end pose and a cue for the next beat. For a three-second ident try gather (0–0.6s), resolve (0.6–1.6s), read (1.6–3s). Spend the longest hold on information viewers need to read. Change pacing to suit the copy.
4. Build the transition around continuity: carry a shared edge, axis, color or contour across the cut. For kinetic type, move phrases by meaning; mask at the line boundary and keep a single semantic text equivalent. For product explainers, follow one real action through cause, feedback and outcome. For data stories, keep scale and identities stable and show the final values without playback.
5. Choose the smallest renderer that fits. Use SVG groups and a shared viewBox for marks and diagrams; HTML/CSS for responsive type; Canvas for dense procedural drawings. Use local Blender for lighting, materials or camera moves when a prerender will do. Use live 3D only when interaction needs it. No paid assets, plugins or remote rendering required.
6. Give the composition a single time coordinate. Derive each layer from local progress clamped between its in/out cues. Use easing for perceived weight, a brief offset for secondary response, and a settled hold. Seek directly to any frame without replaying earlier events. For a loop, compare both pose and velocity across the seam; omit the duplicate last frame on export.
7. Deliver an editable source, poster, playback instructions and placement-specific output. For video, choose pixel dimensions and frame rate before rendering; render a numbered image sequence locally and encode with an available free encoder. Verify the decoded first, middle and final frames, duration, color and legibility. Preserve alpha only when the delivery format and target player support it.
8. Review at normal speed, then scrub the transitions. Check crop and text-safe areas in every requested ratio; recompose vertical layouts instead of blindly cropping. For web, start from a meaningful still, honor reduced motion including preference changes, avoid flashing and provide keyboard-operable playback when appropriate. Verify replay, interruption, and no-script fallback. Report which formats and devices were actually checked.
