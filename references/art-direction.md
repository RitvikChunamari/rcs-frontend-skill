# Distinctive visual craft and anti-template art direction

## Build a visual thesis before components

The one-line visual thesis should connect product meaning to art direction: "A precision instrument for makers, expressed through Swiss editorial grids and tactile project reveals." Define mood, differentiator, content narrative and perceptual hierarchy. Pick a primary motif (e.g. typography-as-architecture, offset print registration, topographic contours, cinematic cropping, modular index cards) and let details echo it.

## Layout and rhythm

- Lay out content in **intentional modules**: hero, proof, project/case content, utility sections, footer. Decide which modules deserve asymmetry; preserve scan patterns for functional UI.
- Use real baseline/column grids, disciplined alignment, optical rather than purely numerical centering, measured whitespace, text measure (roughly 45-75 characters for long reading lines, context dependent), modular responsive shifts.
- Plan visual rhythm: dense/quiet, image/type, light/dark, large/small. Monotonous panels and identical card grids flatten any idea.
- Mobile is a separate composition, not a squashed desktop. Re-sequence content, crop artwork safely, keep CTAs visible and replace hover-only reveals with tap/visible equivalents.

## Typography as the first-class graphic

- Select a usable licensed font family with purposeful weight, width and italic treatment. Prefer self-hosting when license and project constraints allow; subset cautiously.
- Establish display, heading, body, metadata and numeric styles with consistent caps, tracking and line-height. Design specific line breaks at large screens; avoid forced breaks that create mobile overflow.
- Use actual content lengths to test type wrap, baseline shifts, mixed scripts/diacritics, bold emphasis and localization.
- For **Swiss editorial**: disciplined grid, condensed/extended typography contrast, asymmetrical balance, strict typographic hierarchy, precise rules/labels/indexes; use contrast intentionally, not indiscriminately.

## Graphic design beyond generic UI

- Construct a distinct motif through vector systems, typography, art-directed crops, diagrams, patterns, blend modes, tasteful noise or custom shader work. One powerful motif is stronger than five random effects.
- Use real user content/images unless authorized to add or replace assets. Ensure licenses of icons, photos, 3D models and typefaces. Optimize SVG and raster assets.
- Layer with purpose: credible depth from occlusion, perspective, shadow and blur; never use blur indiscriminately to disguise weak structure.
- Use nonliteral textures and chromatic accents sparingly; maintain contrast and legibility.

## Anti-AI-slop review (reject or revise)

- Generic hero says "Transform your experience" with token decorative orbs and three mismatched purple gradient cards.
- Every section appears with the same fade-up on scroll; hover rotates every card; every image is clipped into an arbitrary blob.
- Multiple competing display fonts, unrelated icons, inconsistent shadows/radii, dense glass surfaces or repetitive symmetrical layouts.
- UI has fake charts, implausible numbers, meaningless testimonials, default placeholder paragraphs or nonfunctional buttons.
- Visual design ignores user journey, state changes, device constraints or backend truth.
- A component gallery is pasted together without unified spacing, tokens, semantics or a singular brand logic.

## Premium-polish pass

Compare screenshot references by zones: first impression at 3 seconds, scan at 10 seconds, functional use at 60 seconds. Check optical alignment, heading wraps, icon weights, hairline rendering, masking, image quality/crops, CTA affordance, empty space, focus states, intentional choreography and footer finish. Remove anything that doesn't reinforce the thesis.

## Three creative presets (adapt, never enforce)

- **Editorial / precision:** black/white + one accent, high-contrast large type, strict grids, expressive indexing, one deliberate scrolling transformation, minimal tactile interactions.
- **Cinematic / spatial:** dark-to-light compositions, immersive imagery, controlled depth/parallax, smooth transitions, narrative chapter markers, lower-motion static version.
- **Playful / kinetic utility:** typographic personality, vivid but meaningful accents, spring feedback, clear task completion, localized interactive illustrations, restrained repeating motion.
