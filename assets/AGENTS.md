# RC's Frontend Skill adapter for general coding agents

For any frontend, design, animation, visual UX, browser UI, app interface, 3D or web QA task:

1. Load the complete `SKILL.md` from the `rcs-frontend/` skill folder. Replace this relative path with the actual installed absolute or workspace path.
2. Follow its repo-first, original-art-direction, backend-integrity, responsive, reduced-motion and testing rules. Read only the task-relevant files from `references/`.
3. For existing projects, preserve content, backend functionality, existing working features and user constraints. Do not invent content, routes or project work.
4. Research official sources and live design references only through tools available in this agent. Do not assume Figma/Mobbin/browser MCP or paid accounts are connected.
5. Test the running product, report commands, screenshots and API flows actually checked. Never claim tests or visual review passed without execution.
6. When the user's task requests a change, implement the change instead of stopping after the design plan unless blocked.

This adapter provides **no installation, browser access, secret access, shared agent memory or model quota routing by itself**.
